
# MiniBank — Banking and Payments API

## Overview
A practice banking backend built with Java 21 and Spring Boot.

## Current Features
- Application health endpoint
- REST API versioning
- Maven-based build

## Technology Stack
- Java 21
- Spring Boot 3.5.x
- Maven
- Spring Web
- Bean Validation
- Spring Boot Actuator

## Run Locally
```powershell
.\mvnw.cmd spring-boot:run
```

## API Endpoint

GET /api/v1/health

## Planned Features
- Customer and bank account management
- Fund transfers and transaction ledger
- PostgreSQL persistence
- Unit and integration testing
- Spring Security
- Docker and Kubernetes
- CI/CD using GitHub Actions
